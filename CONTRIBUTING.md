# Contributing

Contributions should improve observable behavior rather than add more motivational prose.

Good changes include:

- a failure case with an expected route;
- a clearer principal-tension test;
- a smaller, more informative pilot;
- a correction to attribution or translation;
- a stronger consent, mental-health, or anti-coercion boundary.

Before opening a pull request:

1. add or update an eval case;
2. run `python scripts/validate_repo.py`;
3. explain which user behavior improves and what regression is prevented;
4. do not add copyrighted source text, personal data, political persuasion, or claims of clinical validation.
